## 📌 Introduction

The **Data Jobs Dashboard 2.0** was created for **job seekers, career switchers, and professionals in the data space** to solve a common problem:  
**understanding the data job market clearly and efficiently.**

Using a real-world **2024 dataset of data job postings**, this dashboard consolidates information on:
- Job demand
- Required skills
- Salary trends
- Geographic distribution

The result is a **single, interactive, and easy-to-use interface** that helps users explore market trends, compensation benchmarks, and in-demand skills across data roles.

---

## 🎯 Dashboard Objectives

- Identify the **most in-demand data roles**
- Analyze **top technical skills per job**
- Compare **median yearly and hourly salaries**
- Explore **job opportunities by country**
- Enable users to interactively filter and drill down into the data
