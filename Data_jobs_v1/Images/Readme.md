## 🧠 Key Metrics Overview

The dashboard highlights high-level KPIs to give users an instant snapshot of the market:

- **Total Job Count:** 479K  
- **Average Skills per Job:** 4.8  
- **Median Yearly Salary:** $113K  
- **Median Hourly Salary:** $47.62  

These metrics dynamically update based on slicer selections.

---

### 🔹 Top Paying Jobs in Data

  - Senior Data Scientist
  - Machine Learning Engineer
  - Senior Data Engineer
  - Software Engineer

## 🛠 Skills Showcased

This project demonstrates end-to-end Power BI proficiency, including:

### 🔹 Data Transformation (ETL)
- Cleaned and shaped raw job posting data using **Power Query**
- Handled missing values and standardized data types
- Created new calculated columns for analysis

### 🔹 DAX & Measures
- Built **implicit and explicit measures**
- Calculated KPIs such as:
  - Median Yearly Salary
  - Median Hourly Salary
  - Job Count
  - Skill per Job
- Used DAX to enable dynamic filtering and aggregation

### 🔹 Data Visualization
- Column, bar, and line charts for trend comparison
- KPI cards for high-level metrics
- Consistent layout and color theme for readability

### 🔹 Dashboard Design
- User-friendly layout focused on clarity
- Clear labeling and intuitive navigation
- Optimized for storytelling and decision-making
